# 03 · Access guides (record these once, send forever)

Four 60-second phone screen recordings. Use your own test Page. Say the steps out loud in simple English and Swahili.
Raswal's **Business Portfolio ID** (16 digits) goes into guide A. Fill it in after you create the portfolio: `ID: ______________`.

**A · Partner access (Route A)**
1. Open Meta Business Suite → Settings → **Business settings**.
2. Users → **Partners** → Add → "Give a partner access to your assets".
3. Enter Raswal's Business Portfolio ID → choose the Page and the ad account → turn on **Manage campaigns** → Save.

**B · Ads access on the Page + link WhatsApp (Route B)**
1. Page → Settings → **Page access** (or Business Suite → Settings → People) → add Raswal's profile or portfolio with **Ads** permission.
2. Page → Settings → **Linked accounts** → WhatsApp → enter the business number → type the code WhatsApp sends.

**C · Create a Page in 5 minutes**
1. Facebook → Pages → Create. Name = the business, category = **Real estate**.
2. Profile picture = their logo, cover = a project photo.
3. Then guide B.

**D · Switch to WhatsApp Business (keeps chats)**
1. Back up chats. 2. Install **WhatsApp Business**. 3. Same number → restore. 4. Add the business name and hours.

Tell clients: "You can remove us in one tap any time. We never see your password."
