# Pilot kit

What you use from "yes" to a live ad in 24 hours. Numbers (KES 5,000, prices) come from `config/pilot.yaml`; the words you send
are the quick replies in the dashboard (Settings → Quick replies). These docs never repeat that copy, they point to it.

| # | Doc | When |
|---|---|---|
| 01 | [Offer form](01-offer-form.md) | the moment they say yes (quick reply `start_pilot`) |
| 02 | [Route checklist](02-route-checklist.md) | the 5 questions, then pick Route A / B / C / Backup |
| 03 | [Access guides](03-access-guides.md) | scripts for the 4 phone screen recordings you send |
| 04 | [WhatsApp set-up call](04-whatsapp-setup.md) | the 20-minute call on their phone |
| 05 | [Campaign sheet](05-campaign-sheet.md) | building the 3 ads in Ads Manager |
| 06 | [The 24-hour clock](06-24h-clock.md) | the timeline and what can go wrong |
| 07 | [Day-7 report](07-day7-report.md) | closing the pilot and asking for the Enquiry Engine |

The promise to clients is **conversations, not sales**. Never say guaranteed, never quote a result you haven't seen.
